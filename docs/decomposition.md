# Декомпозиция дипломного проекта FakeNFT

**Исполнитель:** работаю в одиночку, реализую всё приложение (Каталог, Корзина, Статистика, Профиль).
**Стек (по ТЗ):** SwiftUI, MVVM (`@Observable`), iOS 17.0+, сетевые сервисы на `actor`, модели `Sendable`, Swift Concurrency (`async/await`, `async let`, `withTaskGroup`), без GCD и completion-ов, UI обновляется только на `@MainActor`.
**Таск-трекер:** https://github.com/users/voplachko/projects/4

Оценка и факт указаны в часах. Столбец «Факт» заполняется по ходу работы.
